安全

明确的边界

本地数据

账户保存在应用私有目录，默认是明文 JSON，没有主密码。应用没有网络权限，也不会上传账户或日志。

  • 关闭 Android 自动备份
  • 卸载应用会删除本地数据
  • debug / root 设备仍可能读取明文

加密备份

设置里的“加密备份”只作用于导出的 .mixa 文件，不改变本地数据。

  • 使用标准认证加密
  • 密码不保存，忘记无法恢复
  • 支持在导入页直接恢复
